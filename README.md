# Свой ИИ, который учится в чате Gemini

Телеграм-бот со своим мозгом, который учится прямо в разговоре.
Единственный источник знаний — **живой чат gemini.google.com**. Никакого поиска
в Google, никакой Википедии: бот сам открывает composer «Спросить Gemini»,
печатает туда сообщение, дожидается полного ответа и запоминает его.

## Как он думает

```
пользователь пишет «Привет»
        │
        ├─ вопрос самостоятельный? ──нет──┐   («а почему?», «продолжи» —
        │                                 │    смысл только в контексте)
       да                                 │
        │                                 │
   ищу в своей памяти                     │
        │                                 │
   нашёл похожий (≥ 0.88)?                │
        │           └──нет────────────────┤
       да                                 │
        │                                 ▼
   отвечаю сам                   открываю чат Gemini,
   (мгновенно, 0 запросов)       печатаю сообщение,
                                 забираю ответ
                                         │
                                  ЗАПОМИНАЮ пару
                                  вопрос → ответ
```

Чем дольше бот работает, тем чаще отвечает своим умом — долю видно в `/admin`.

Из ответов вычищаются служебные подписи интерфейса — «Ответ Gemini»,
«Показать детали» и подобные: пользователь видит только сам ответ.

## Медиа в чате

Боту можно прислать не только текст:

| Что прислали | Что делает бот |
|---|---|
| фото (в т.ч. альбомом) | прикрепляет в чат Gemini и отвечает по картинке |
| голосовое | Gemini слушает и отвечает так, будто это был текст |
| видео и кружки | смотрит и отвечает по содержимому |
| аудио, документы (PDF, txt, csv, код) | читает файл и отвечает по нему |
| стикеры | реагирует на картинку стикера |

Подпись к файлу становится вопросом. Без подписи бот сам формулирует
просьбу («Посмотри на это изображение…»).

Файлы уходят в тот же чат Gemini. Рабочий путь снят с живой страницы:
кнопка **«Загрузка и инструменты»** у поля ввода → в DOM появляется
`input.hidden-file-input` → файлы кладутся прямо в него → меню закрывается.
Если разметка поменяется, есть запасные пути: другие `input[type=file]`,
системный диалог выбора и перетаскивание файла в окно.

Способ засчитывается, только если превью файла реально появилось в композере
(`uploader-file-preview`, `gem-media-attachment`). Не появилось — бот берёт
следующий способ, а если не сработал ни один, честно говорит об этом вместо
отправки пустого сообщения. Какой способ сработал, видно в `/admin` →
«Состояние».

Ответы по файлам **не попадают в базу знаний**: картинка каждый раз новая,
запоминать тут нечего. А вот в контекст диалога они ложатся с пометкой
(`[фото] что это за кот?`), поэтому следующий вопрос «а порода какая?»
бот поймёт правильно.

Ограничения: Telegram не отдаёт ботам файлы больше 20 МБ, анимированные
стикеры (`.tgs`) Gemini не читает. Скачанное живёт в `data/tmp` только на
время ответа и сразу удаляется.

## Что нужно

* Python 3.9 или новее
* установленный Google Chrome
* аккаунт Google (обычный, бесплатный)

## Установка

Открой терминал в папке с проектом:

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

Playwright использует уже установленный Google Chrome. Если Chrome нет:

```bash
.venv/bin/python -m playwright install chromium
```

## Настройка

Скопируй шаблон настроек и заполни два поля:

```bash
cp .env.example .env
```

* `BOT_TOKEN` — создай бота у [@BotFather](https://t.me/BotFather) командой
  `/newbot` и вставь выданный токен;
* `ADMIN_ID` — твой числовой Telegram ID, узнать можно у
  [@userinfobot](https://t.me/userinfobot). Только с этого ID открывается
  админ-панель.

Остальное можно не трогать — значения по умолчанию рабочие.

> `.env` уже прописан в `.gitignore`. Не выкладывай его никуда: по токену
> любой сможет управлять твоим ботом.

## Шаг 1. Разовый вход в Gemini (делаешь руками)

```bash
.venv/bin/python tools/gemini_login.py
```

Откроется окно браузера. Там нужно:

1. закрыть окно Google про cookie — **вариант выбираешь сам**
   (для приватности достаточно «Отклонить все»);
2. нажать «Войти» и зайти в свой Google-аккаунт;
3. дождаться поля «Спросить Gemini» и вернуться в терминал, нажать Enter.

Скрипт скажет `✅ Готово`. Сессия сохранится в `data/gemini_profile` — больше
входить не придётся. Пароль скрипт не спрашивает и нигде не хранит.

## Шаг 2. Запуск

```bash
.venv/bin/python main.py
```

Пока бот работает, окно Chrome должно оставаться открытым — это и есть его
«рука», которой он пишет в чат. Чтобы окно не мешало, после успешного входа
поставь в `.env`:

```
GEMINI_WEB_HEADLESS=true
```

Если Gemini начнёт капризничать в фоновом режиме — верни `false`.

## Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | всем | приветствие |
| `/clear` | всем | забыть контекст диалога (выученное остаётся) |
| `/admin` | только `ADMIN_ID` | панель управления |
| `/block ID`, `/unblock ID` | админу | заблокировать пользователя |

Обычный пользователь просто пишет сообщения или шлёт файлы — никаких
команд ему не нужно.
В подсказке по `/` у него видно `/start` и `/clear`, у админа ещё и `/admin`.

## Админ-панель

* **📊 Обзор** — пользователи, сообщения, доля ответов своим умом, скорость,
  размер базы знаний, сообщения с вложениями с разбивкой по типам, ошибки.
* **📈 Активность** — 7 дней с диаграммой.
* **👥 Пользователи** — топ активных, новички, блокировка.
* **🧠 База знаний** — что выучено, что чаще всего пригождается, поиск по
  памяти, удаление записи, полная очистка.
* **🩺 Состояние** — жив ли доступ к Gemini, аптайм, журнал событий.
* **⚙️ Настройки** — вкл/выкл обучение, приоритет своей памяти, самообучение,
  порог узнавания.
* **📢 Рассылка** — с предпросмотром и подтверждением.

## Самообучение

В настройках можно включить «Самообучение»: раз в 15 минут бот сам придумывает
вопросы по темам, которые уже встречались, задаёт их Gemini и запоминает ответы.
По умолчанию выключено, чтобы не расходовать лимиты впустую.

## Настройки (.env)

| Ключ | Смысл |
|---|---|
| `TEACHER` | `web` — чат gemini.google.com, `api` — официальный бесплатный Gemini API |
| `GEMINI_WEB_HEADLESS` | прятать окно браузера |
| `GEMINI_WEB_NEW_CHAT` | каждый вопрос в новом чате Gemini (контекст держит свой ИИ) |
| `SIM_THRESHOLD` | порог узнавания вопроса, 0.88 по умолчанию |
| `MAX_MEDIA_MB` | максимальный размер файла, до 20 |
| `MAX_ALBUM` | сколько файлов брать из одного альбома |
| `CONTEXT_TURNS` | сколько реплик диалога помнить |

### Запасной режим `api`

Если браузерный чат отвалится, можно за минуту переключиться: взять бесплатный
ключ на <https://aistudio.google.com/apikey>, вписать `GEMINI_API_KEY` и
поставить `TEACHER=api`. Это те же модели Gemini от Google, только без окна
браузера. Вся выученная база знаний при этом сохраняется.

## Структура

```
main.py                     запуск бота
config.py                   чтение .env
ai/text.py                  нормализация и похожесть вопросов
ai/media.py                 типы файлов, временное хранилище, формулировки
ai/storage.py               SQLite: юзеры, контекст, знания, статистика
ai/brain.py                 «вспомнить или спросить учителя и запомнить»
ai/autolearn.py             самообучение в фоне
ai/prompt.py                как ИИ формулирует запрос учителю
ai/providers/gemini_web.py  работа в чате gemini.google.com
ai/providers/gemini_api.py  запасной путь через Gemini API
tgbot/handlers_user.py      чат с пользователем
tgbot/handlers_admin.py     админ-панель
tools/gemini_login.py       разовый вход в Google
data/brain.db               вся память бота
```

## Важное

* Токен бота лежит в `.env`. Если файл куда-то попадёт — перевыпусти токен
  у @BotFather.
* В `data/` появятся база знаний бота и сессия твоего Google-аккаунта.
  Эту папку нельзя никуда выкладывать — она уже в `.gitignore`.
* Автоматизация веб-интерфейса Gemini не предусмотрена правилами Google:
  вёрстка чата может меняться, а аккаунт — получать капчу. Селекторы собраны
  с запасом и обновляются в `ai/providers/gemini_web.py`, но если чат
  перестанет отвечать, самый быстрый выход — режим `api`.
